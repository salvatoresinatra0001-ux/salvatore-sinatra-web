02 / Criteri

Una directory
affidabile.

Non vengono aggiunti link a domini in preparazione come se fossero già attivi. Ogni nodo ha una funzione editoriale riconoscibile, una destinazione esplicita e un rapporto chiaro con il progetto principale.

La presenza di un collegamento non certifica lo stato corrente di servizi esterni, né conferisce diritti di riutilizzo a fotografie, opere o materiali di terzi.
