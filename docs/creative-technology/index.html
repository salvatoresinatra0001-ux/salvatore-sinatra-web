03 / Architettura

Dal repository
al sito.

Source of truth / Version control
Git → Web
Commit · Build · Verify · Publish

Questo ecosistema nasce da pagine editoriali versionate nel repository pubblico. Ogni aggiornamento deve distinguere preparazione, commit, deploy e verifica della versione effettivamente pubblicata.

Le tecnologie elencate descrivono strumenti e aree operative: non implicano certificazioni o servizi terzi attivi non verificati.
