# salvatore-sinatra-web
Repository del sito personale di Salvatore Sinatra, fotografo freelance e artista visivo. Portfolio e archivio editoriale dedicati a fotografia fine art, bianco e nero, ritratto, paesaggio, architettura e ricerca visiva; con progetti autoriali, comunicazione visiva e sperimentazione tra percezione, immagine e tecnologie creative. Progetto in corso.
